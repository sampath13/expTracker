# S1.9: Mobile — Register Screen

**Epic:** 1 — Authentication & User Management
**Depends-on:** S0.1, S0.2, S0.11, S1.2
**Priority:** HIGH

## Context
Build the registration screen with email, password, mobile number, and two consent checkboxes. The first checkbox (data storage consent) is required and cannot be unchecked. The second (community contribution) defaults to checked but is optional. On success, the user is directed to the login screen — not auto-logged-in.

## Scope
- Register screen with email, password, mobile (+65 prefix) fields
- Two consent checkboxes: data storage (required, locked), community contribution (optional, default ON)
- Each consent has explanatory text and links to learn more (expandable inline)
- Mobile number validation: Singapore format (starts with 8 or 9, 8 digits), formatted display
- On success: confirmation message, navigate to login screen
- On error: inline field-level errors (email taken, validation failures)
- Reusable `ConsentCheckbox` component with expandable description
- **Out of scope:** Email verification, captcha

## Acceptance Criteria
1. All fields filled and valid → account created → navigates to login
2. Email already taken → inline error shown
3. Password < 8 chars → field-level error, button disabled
4. First checkbox cannot be unchecked; second defaults to checked and can be toggled
5. Mobile number validates Singapore format
6. Both consent descriptions expand to show privacy details
7. Loading spinner on button during API call

## Definition of Done
- [ ] RegisterScreen with validated form fields
- [ ] ConsentCheckbox component with expandable details
- [ ] Mobile number validation + formatting
- [ ] API integration: calls register endpoint
- [ ] Post-registration navigation to LoginScreen
- [ ] Error handling for network, validation, duplicates
- [ ] Ready for end-to-end auth flow test
