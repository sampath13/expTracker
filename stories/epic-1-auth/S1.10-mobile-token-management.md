# S1.10: Mobile — Auth State, Token Management & Navigation Guard

**Epic:** 1 — Authentication & User Management
**Depends-on:** S0.2, S0.11, S1.3, S1.5
**Priority:** HIGH

## Context
Implement the Zustand auth slice with full token lifecycle management and wire it to the root navigator. On app launch, restore stored tokens from secure storage and validate them. If the JWT is expired, attempt a silent refresh. If the refresh token is also expired, redirect to login. Unauthenticated users see the auth flow (login/register); authenticated users see the main app with bottom tabs. This is the central auth guard every authenticated screen depends on.

## Scope
- Complete `authStore` implementation: login, loginWithGoogle, setTokens, logout actions
- `initialize()` action: called on app launch — loads tokens from Keystore, checks JWT expiry, attempts silent refresh if expired
- JWT decode and expiry check utility
- Token persistence layer: save tokens to Keystore on login, clear on logout
- App.jsx calls `initialize()` on mount; shows SplashScreen during auth check
- Logout clears Keystore and resets all auth state
- SplashScreen component: simple loading view shown during initial token check (sub-second)
- Update `RootNavigator` to conditionally render: `isAuthenticated → AppNavigator`, else → AuthStack
- `AuthStack` navigator with three screens: Login, Register, MobileEntry
- SplashScreen shown while `isLoading` is true (initial token check)
- Remove hardcoded `isAuthenticated = true` from S0.1
- Logout → `isAuthenticated` becomes false → RootNavigator re-renders to AuthStack
- Navigation state fully resets on auth transition (React Navigation handles this by unmounting)
- **Out of scope:** Biometric unlock, multi-device token sync, deep linking

## Acceptance Criteria
1. App launch: tokens restored from Keystore, user auto-logged in (no login screen flash)
2. Expired JWT triggers silent refresh on next API call (via S0.11 interceptor)
3. Expired refresh token → user logged out, shown login screen
4. Logout clears Keystore completely
5. Token state persists across app kills and relaunches
6. SplashScreen shown during initial auth check
7. Network error during refresh → graceful fallback to login screen
8. No stored tokens → LoginScreen shown
9. Valid stored tokens → Home tab shown
10. Login success → instant switch to AppNavigator without flash
11. Logout → instant switch to AuthStack without flash
12. Back button after logout does not navigate to authenticated screens
