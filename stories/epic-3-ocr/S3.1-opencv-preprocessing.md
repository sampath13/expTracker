# S3.1: OpenCV Preprocessing Pipeline

**Epic:** 3 — OCR Pipeline
**Depends-on:** S0.8
**Priority:** HIGH

## Context
Implement the image preprocessing pipeline using OpenCV. Raw receipt photos are often tilted, low-contrast, noisy, and unevenly lit. The preprocessing normalises them before PaddleOCR runs, significantly improving accuracy. Each preprocessing step is configurable and can be selectively enabled.

## Scope
- Four preprocessing steps: deskew (straighten tilted receipts via Hough line transform), contrast enhancement (CLAHE), noise reduction (bilateral filter), binarization (Otsu thresholding)
- Pipeline orchestration function that runs steps in optimal order: deskew → contrast → denoise → binarize
- Steps configurable via parameter — any step can be skipped
- Debug mode: saves intermediate images for development when `DEBUG=true`
- Processing time logged per step for monitoring
- Unit tests for each individual step and the full pipeline
- **Out of scope:** ML-based preprocessing, receipt template matching

## Acceptance Criteria
1. `deskew` correctly straightens a tilted receipt (visual verification)
2. `contrast` visibly improves faint thermal paper text
3. `denoise` reduces grain while preserving text edges
4. `binarize` produces clean black text on white background
5. Full pipeline runs all four steps and returns preprocessed image
6. Each step can be selectively skipped
7. Full pipeline processes a receipt in < 500ms
8. Debug mode saves intermediate images per step

## Definition of Done
- [ ] All four preprocessing functions implemented
- [ ] Pipeline orchestration with configurable step selection
- [ ] Debug output for development
- [ ] Unit tests per step + full pipeline
- [ ] Performance: < 500ms
- [ ] Ready for S3.2 (PaddleOCR integration)
