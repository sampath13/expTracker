# S4.7: Mobile — Bill Detail Screen

**Epic:** 4 — Confirmation & Expense History
**Depends-on:** S4.6, S5.1
**Priority:** HIGH

## Context
The bill detail screen shows all items from a confirmed bill with their prices. Each item row displays a color dot indicating how its price compares across chains (using comparison data from S5.1). Expanding an item reveals "Available for less at [Chain]" details. This is where the comparison engine's results first surface to the user.

## Scope
- Bill header: retailer name + outlet, date, total amount + GST
- Items list with comparison color dots per item (green ≤5%, grey 5-15%, amber 15-30%, red >30%, neutral for no data)
- Expandable comparison panel per item: "Available for less at [Chain]: $X.XX per [unit]", list of chains sorted cheapest first, trust line ("Based on N receipts, last reported X days ago"), or "Not enough comparison data yet" for items without matches
- Fetches bill detail from API; for each matched item, fetches comparison data
- Falls back to WatermelonDB cache when offline (bill visible, comparison may be stale/unavailable)
- "Delete Bill" option with confirmation dialog — removes bill and its pool contributions
- Neutral framing enforced: never "expensive" or "rip-off" — per architecture.md section 8.4
- Color dots accompanied by text labels for accessibility (not just color)

## Acceptance Criteria
1. Bill detail shows retailer, date, total, and all items
2. Each item has color dot based on comparison tier (or neutral if no data)
3. Expanding item shows price comparison with trust indicators
4. No-data items show "Not enough comparison data yet" explanation
5. "Delete Bill" removes bill and navigates back to expense list
6. Offline: bill loads from cache (items visible, comparison may be unavailable)
7. All comparison text uses neutral "available for less at" framing
