# S4.6: Mobile — Expense List Screen

**Epic:** 4 — Confirmation & Expense History
**Depends-on:** S0.1, S0.2, S4.5
**Priority:** HIGH

## Context
Build the Expenses tab — a paginated list of bills showing date, retailer, total, and item count. Pulls from WatermelonDB cache for offline access; refreshes from API when online. Tapping a row opens Bill Detail (S4.7). Includes empty, loading, and error states.

## Scope
- `ExpenseListScreen` with FlatList, pull-to-refresh, and infinite-scroll pagination
- `expensesStore` implementation: fetchBills (cloud), refreshBills, removeBill (optimistic removal)
- Each row: date (DD Mon format), retailer name, total amount (SGD), item count
- Header: monthly total spending (computed from visible bills for current month)
- Empty state: illustration + text + "Scan" button (navigates to camera)
- Loading state: skeleton placeholder rows
- Error state: retry button
- Swipe-to-delete on rows: confirmation dialog → DELETE API call → optimistic removal from list
- Auto-refresh on tab focus (useFocusEffect)
- Falls back to WatermelonDB cache when API is unreachable
- **Out of scope:** Search/filter, date-range filtering, category grouping

## Acceptance Criteria
1. Expense list loads bills on tab focus
2. Infinite scroll loads next page at bottom
3. Pull-to-refresh re-fetches from server
4. Each row shows date, retailer, total, item count
5. Tapping row navigates to BillDetailScreen
6. Empty/loading/error states all functional
7. Offline: cached bills visible
8. New bill appears after confirm + tab re-focus

## Definition of Done
- [ ] ExpenseListScreen with FlatList + pagination + pull-to-refresh
- [ ] expensesStore with fetch, refresh, remove
- [ ] All UI states: empty, loading, error, data
- [ ] Swipe-to-delete with confirmation
- [ ] Tab-focus refresh
- [ ] WatermelonDB cache fallback
- [ ] Ready for S4.7 (bill detail)
