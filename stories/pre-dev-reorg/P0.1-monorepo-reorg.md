# P0.1: Monorepo Folder Reorganisation

**Epic:** Pre-Dev — Monorepo Setup
**Depends-on:** None
**Priority:** HIGH — must complete before Epic 0 stories begin

## Context

The repository currently has a flat structure with documentation, the threader app, decision threads, and story breakdowns all at the root level. Before any implementation work starts, the repo must be reorganised into the target monorepo layout defined in `.monorepo-structure.md`. This ensures all subsequent stories (Epic 0–8) create files in the correct locations from the start.

Target layout follows a **Turbo-adapted `apps/` + `packages/`** pattern: four deployable apps under `apps/`, documentation under `docs/`, infrastructure under `docker/`, and cross-cutting scripts under `scripts/`.

## Scope

| In | Out |
|---|---|
| Create all target directories | Scaffolding app internals (Epic 0) |
| Move existing files to target locations | Creating new files |
| Fix threader path after move | Changing threader functionality |
| Verify threader still works | Running docker compose (no services yet) |
| Verify all relative references still resolve | Git history preservation (just `git mv`) |
| Remove empty directories after moves | — |

## Story Breakdown

### Step 1 — Create target directories

```bash
mkdir -p apps docs docker/postgres docker/s3ninja scripts/seed .github/workflows
```

Verify: all new directories exist and are empty.

### Step 2 — Move documentation to `docs/`

```bash
git mv architecture.md docs/architecture.md
git mv epics.md docs/epics.md
git mv product-overview.md docs/product-overview.md
git mv open-questions.md docs/open-questions.md
```

Verify: root is clean of `.md` files (except `README.md` and `.monorepo-structure.md`).

### Step 3 — Move `threader/` to `apps/threader/`

```bash
git mv threader apps/threader
```

**Critical:** Update `apps/threader/server.js:11` — the `THREADS_DIR` path is currently `path.join(__dirname, '..', 'threads')` (resolves from `threader/` → `threads/`). After the move it must be:

```js
const THREADS_DIR = path.join(__dirname, '..', '..', 'threads')
```

This walks up from `apps/threader/` → `apps/` → repo root → `threads/`.

Verify: `npm run dev` from `apps/threader/` starts successfully and the server can read thread JSON files.

### Step 4 — Verify `stories/` and `threads/` remain at root

These directories do not move — they are referenced by AI agents and the threader app respectively. Confirm both exist at repo root and contain their expected files.

### Step 5 — Verify `packages/` is not created

No shared packages exist yet. The `packages/` directory is documented for future use but should NOT be created now. Creating empty `packages/` would mislead tooling and agents.

### Step 6 — Clean up

- Remove any empty directories left behind after `git mv`
- Update `.gitignore` if root-level additions need it
- No `package.json` or workspace config at root — this is a multi-runtime repo

### Step 7 — Final verification

```bash
# Check target structure matches .monorepo-structure.md
ls -la apps/
ls -la docs/
ls -la docker/
ls -la scripts/
ls -la .github/workflows/

# Confirm no orphaned files at root
ls *.md  # should show only README.md and .monorepo-structure.md

# Confirm threader works
cd apps/threader && npm install && npm run dev
# Visit http://localhost:5173 — should load thread viewer
```
