# S2.2: Mobile — Camera Screen

**Epic:** 2 — Receipt Capture & Image Upload
**Depends-on:** S0.1, S0.5
**Priority:** HIGH

## Context
Build the full camera capture screen. Uses the CameraView component from S0.5 with permission handling from S0.4. The screen lets users frame a receipt, capture a photo, and preview the result. Quality checks run automatically after capture — blurry images show a retake prompt.

## Scope
- Full-screen camera screen in the Home stack: `ScanReceiptScreen`
- Uses CameraView (S0.5) — live preview, capture button, flash toggle
- After capture: 1-second preview with quality check result overlay
- Blurry → overlay with "Retake" and "Use Anyway" buttons
- Sharp → auto-proceeds (green checkmark, then navigate)
- X close button with discard confirmation if photo was taken but not saved
- Status bar hidden on this screen for full immersion
- Home screen access: FAB or prominent "Scan Receipt" card
- `HomeStack` navigator updated: Home → ScanReceipt → UploadProgress → ConfirmOCR
- **Out of scope:** Gallery import, video capture, multi-image stitching

## Acceptance Criteria
1. Camera preview fills screen with live view
2. Capture button takes a photo, shown in preview overlay
3. Quality check runs automatically — blurry shows retake prompt, sharp proceeds
4. Flash toggle cycles auto/on/off
5. X button closes camera, returns to Home
6. Discard dialog if user navigates back with unsaved photo
7. Camera permission denied shows PermissionGate from S0.4

## Definition of Done
- [ ] ScanReceiptScreen with camera integration
- [ ] Capture + preview flow
- [ ] Quality check integration
- [ ] Flash toggle
- [ ] Back/close with discard confirmation
- [ ] Home stack navigator updated
- [ ] Ready for S2.3 (blur detection), S2.4 (upload flow)
