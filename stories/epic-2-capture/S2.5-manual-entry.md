# S2.5: Mobile — Manual Entry Fallback

**Epic:** 2 — Receipt Capture & Image Upload
**Depends-on:** S0.1, S0.2, S1.10
**Priority:** MEDIUM

## Context
Provide a manual bill entry flow for users who can't or prefer not to use the camera (permission denied, OCR fails, device has no camera). Users can type in retailer name, date, and item details. Manual bills go through the same confirmation and contribution pipeline as scanned bills, just without OCR.

## Scope
- `ManualEntryScreen`: retailer dropdown (6 chains + "Other"), outlet text field, date picker, dynamic item list
- Item rows: name, qty, unit picker, unit price — with add/delete functionality
- Auto-calculate per-item and grand totals
- `POST /bills/manual` backend endpoint — creates bill directly (no OCR, no S3 image)
- Manual bills flow to Comparison Pool via same contribution pipeline (if user has consent)
- Accessible from: Home screen secondary button, camera permission denied state, OCR error state
- On save: success feedback, navigate to Home, refresh expense list
- **Out of scope:** Saved drafts, recurring bills

## Acceptance Criteria
1. User can select retailer from dropdown with 6 preset chains + custom
2. Multiple items can be added with name, qty, unit, price
3. Total auto-calculated as items are added
4. Save creates bill via POST /bills/manual
5. Success → Home with confirmation feedback
6. Items can be deleted (swipe) with undo snackbar
7. Date defaults to today, editable via picker
8. Accessible from all relevant failure states

## Definition of Done
- [ ] ManualEntryScreen with all form fields
- [ ] POST /bills/manual backend endpoint
- [ ] Item list with add/delete
- [ ] Retailer dropdown with 6 chains + Other
- [ ] Save → success → Home flow
- [ ] Available from camera deny and OCR error states
- [ ] Ready to serve as fallback for capture failures
