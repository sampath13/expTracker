# S0.11: Mobile — API Client Module

**Epic:** 0 — Project Scaffold & Cross-Cutting Concerns
**Depends-on:** S0.2
**Priority:** HIGH

## Context
Create the shared API client module consumed by every mobile story. This module provides: (1) a configured HTTP client with JWT interceptor (attach token to all requests), (2) silent refresh retry on 401 responses, and (3) typed service wrappers for auth endpoints. Extracting this into an Epic 0 cross-cutting story avoids burying foundational infrastructure inside a login screen story, making the dependency explicit for all downstream consumers.

## Scope
- API client module (`apps/mobile/src/services/api.js`): axios or fetch wrapper with base URL config from env
- Request interceptor: attach JWT from `authStore` to `Authorization: Bearer` header on every request
- Response interceptor: on 401, attempt POST /auth/refresh with stored refresh token; on success, update tokens in authStore and retry original request; on failure, clear auth state and redirect to login
- Queue concurrent requests during refresh to avoid multiple simultaneous refresh calls
- Auth service module (`apps/mobile/src/services/authService.js`): `login(email, password)`, `register(email, password, mobile, consents)`, `googleLogin(idToken)`, `refreshToken(refreshToken)`
- Typed request/response contracts in `apps/mobile/src/types/api.ts`
- Timeout default (15s), configurable per-call
- **Out of scope:** Biometric auth, request caching, offline queue

## Acceptance Criteria
1. API client attaches JWT to all outgoing requests automatically
2. On 401 response, interceptor attempts silent token refresh exactly once
3. Successful refresh: tokens updated in authStore, original request retried with new JWT
4. Failed refresh: auth state cleared, navigation to login
5. Concurrent requests during refresh are queued and replayed after refresh succeeds
6. authService exposes typed methods for all auth endpoints (login, register, googleLogin, refreshToken)
7. Network timeout returns clear error (no hanging requests)
