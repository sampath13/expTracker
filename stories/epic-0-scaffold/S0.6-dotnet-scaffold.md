# S0.6: .NET 10 Backend Scaffold

**Epic:** 0 — Project Scaffold & Cross-Cutting Concerns
**Depends-on:** None
**Priority:** HIGH

## Context
Create the .NET 10 Web API solution in `apps/api/` following the 3-tier clean architecture: `ExpTracker.Api` (presentation — controllers, middleware), `ExpTracker.Core` (business logic — services, interfaces, DTOs), and `ExpTracker.Infrastructure` (data access — DbContexts, EF Core configs, external service clients). Configure the middleware pipeline (CORS, auth, Swagger, Serilog) and wire connection strings and service URLs in configuration. This is the backend entry point that all other backend stories build on.

## Scope
- .NET 10 LTS solution in `apps/api/` with three projects:
  - `src/ExpTracker.Api/` — controllers, middleware, Program.cs, DI wiring
  - `src/ExpTracker.Core/` — services (stubs), interfaces, DTOs/Models
  - `src/ExpTracker.Infrastructure/` — data (DbContext stubs), migrations folder, external services
- `tests/` directory with `ExpTracker.Api.Tests/`, `ExpTracker.Core.Tests/`, `ExpTracker.Infrastructure.Tests/`
- NuGet packages: EF Core 10, Npgsql, ASP.NET Identity, JWT Bearer, AWS SDK (S3), Serilog, Swashbuckle
- `appsettings.json` with connection strings for both databases (Personal + Comparison), JWT config, S3Ninja local endpoint, Google auth placeholders, OCR service URL
- `Program.cs` middleware pipeline in correct order: CORS, Auth, Authorization, Controllers, Swagger, Health Checks
- Health check endpoint returning DB and storage statuses
- Serilog configured: console in dev, structured JSON in prod
- Layer dependency: Api → Core ← Infrastructure (Core must not reference Infrastructure)
- **Out of scope:** Migrations, actual endpoints, Docker integration

## Acceptance Criteria
1. `dotnet build` succeeds with zero errors and warnings across all three projects
2. `dotnet run --project src/ExpTracker.Api` starts the API on `http://localhost:5000`
3. Swagger UI loads at `/swagger` with no errors
4. `GET /health` returns 200 (DBs show Unhealthy until PostgreSQL is running — expected)
5. Configuration values load correctly from `appsettings.json`
6. CORS headers present in responses
7. Project references follow clean architecture: Api references Core; Infrastructure references Core; Core references nothing
8. Test projects compile and reference correct projects

## Definition of Done
- [ ] .NET 10 SDK installed, solution created in `apps/api/`
- [ ] Three projects: Api, Core, Infrastructure with correct project references
- [ ] All required NuGet packages at correct versions per project
- [ ] `Program.cs` with proper middleware ordering
- [ ] `appsettings.json` with all connection strings and service URLs
- [ ] Health check endpoint returns structured status
- [ ] Serilog logging to console
- [ ] Test projects scaffolded
- [ ] Ready for S0.7 (migrations), S1.1 (Identity), S3.7 (OCR orchestration)
