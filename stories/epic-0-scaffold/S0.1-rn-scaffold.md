# S0.1: React Native Project Scaffold

**Epic:** 0 — Project Scaffold & Cross-Cutting Concerns
**Depends-on:** None
**Priority:** HIGH

## Context
Initialize a bare React Native project (no Expo) in `apps/mobile/` and wire up the navigation framework. This is the entry point for all mobile feature stories. The app needs a bottom tab navigator with four tabs (Home, Expenses, Compare, Settings), each wrapping its own stack navigator for drill-down screens. The `apps/` directory already exists from the P0.1 monorepo reorganisation.

## Scope
- Bare React Native project in `apps/mobile/` with Android target
- React Navigation v6 with Bottom Tab + Stack navigators
- Four placeholder screens (one per tab), each showing only a label
- Path aliases configured (e.g., `@screens`, `@components`, `@store`)
- ESLint + Prettier configured and passing
- Verified building and launching on Android emulator without errors
- **Out of scope:** Feature screens, business logic, iOS build

## Acceptance Criteria
1. App launches on Android emulator with a visible bottom tab bar
2. All four tabs selectable and render their corresponding placeholder screen
3. No console errors on launch
4. Linting passes with zero errors

## Definition of Done
- [ ] Project builds and runs on Android emulator
- [ ] Navigation folder structure follows architecture.md section 2.2
- [ ] ESLint + Prettier configured
- [ ] Code committed — ready for S0.2, S0.4, S0.5
