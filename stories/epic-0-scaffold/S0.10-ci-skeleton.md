# S0.10: CI Skeleton

**Epic:** 0 — Project Scaffold & Cross-Cutting Concerns
**Depends-on:** S0.9
**Priority:** LOW

## Context
Set up the GitHub Actions CI workflows that run linting, tests, and build verification on every push. Three workflow files: one per tier (mobile, API, OCR). No deployment step. Pipeline failures block merging.

## Scope
- `.github/workflows/ci-mobile.yml` — `npm ci`, lint (ESLint), typecheck (TypeScript), Jest tests (no emulator build)
- `.github/workflows/ci-api.yml` — `dotnet restore`, `dotnet build`, `dotnet test`, `dotnet format --verify-no-changes`
- `.github/workflows/ci-ocr.yml` — `pip install`, `ruff check`, `pytest`
- Each workflow triggers on push (paths-filtered to its own `apps/` directory) and on PR to main
- Test projects for .NET and Python: each must include at least one real assertion (e.g., verify a controller returns 200 on health check endpoint, verify OCR /health endpoint returns { status: "ok" } with 200 status code)
- `.editorconfig` for .NET formatting rules (at repo root)
- Branch protection configured in GitHub repo settings (not in code)
- **Out of scope:** Deployment, integration tests, emulator-based Android builds, threader CI (not a production app)

## Acceptance Criteria
1. All three CI workflows trigger on every push to their respective paths
2. Mobile CI: lint + typecheck passes
3. API CI: build + test + format check passes
4. OCR CI: lint + pytest passes
5. .NET tests include at least one real assertion (e.g., health endpoint returns 200; DI container resolves DbContext)
6. Python tests include at least one real test assertion (e.g., GET /health returns 200 with model_status field)
7. Intentional lint/build failure in any tier causes only that tier's workflow to fail
8. CI badge(s) in README show passing status

## Definition of Done
- [ ] `ci-mobile.yml`, `ci-api.yml`, `ci-ocr.yml` with correct platform-specific steps and path filters
- [ ] .NET test project with at least one real integration/unit test
- [ ] Python test project with at least one real test assertion
- [ ] Linting configured and passing for all three tiers
- [ ] `.editorconfig` created
- [ ] CI badge(s) in README
- [ ] Ready for all future stories — CI runs on every push
