# S6.2: Seed Price Data Formatting Script

**Epic:** 6 — Crowdsourced Pool & Seed Data
**Depends-on:** S6.3 (product definitions)
**Priority:** HIGH

## Context
Create a script in `scripts/seed/` that takes collected price data (CSV/spreadsheet from field research) and converts it into validated `scripts/seed/seed-prices.json` consumable by the S6.3 loader. Separates the non-engineering price collection activity from the software deliverable. The script validates all entries for structural correctness and produces a commit-ready JSON file.

## Scope
- Script lives in `scripts/seed/` alongside seed data JSON files
- Accept CSV input: columns for canonical_name, chain, outlet, price, unit, month
- Validate each row: canonical_name matches a product in `scripts/seed/seed-data.json` (from S6.3), chain is a known retailer, price is positive number, unit is valid unit string, month is YYYY-MM format
- Report validation errors: unknown products, unknown chains, invalid prices, missing fields
- Transform valid rows into `scripts/seed/seed-prices.json`: array of { canonical_name, chain, outlet, price, unit, month }
- Deduplicate: same product + chain + outlet + month + price → keep one entry, warn
- Output load summary: total rows processed, valid entries, errors skipped, duplicates merged
- Example CSV template committed to `scripts/seed/` for field researchers to fill in
- **Out of scope:** Automated price scraping from retailer websites, ongoing price updates, manual price collection itself

## Acceptance Criteria
1. Script converts a valid CSV to seed-prices.json with correct structure
2. Unknown canonical_names are flagged as errors with row number
3. Unknown chain names are flagged as errors with row number
4. Invalid prices (zero, negative, non-numeric) are flagged
5. Invalid month formats are flagged
6. Duplicate (product, chain, outlet, month, price) entries are merged with warning
7. Output JSON ready for S6.3 loader consumption
8. Example CSV template committed to repo with column headers and sample rows

## Definition of Done
- [ ] Price formatting/validation script
- [ ] CSV input parser with header validation
- [ ] Row-level validation with detailed error reporting
- [ ] Deduplication logic for identical price entries
- [ ] Summary output: valid/invalid/duplicate counts
- [ ] Example CSV template for field researchers
- [ ] Ready for S6.3 (seed data loader)
