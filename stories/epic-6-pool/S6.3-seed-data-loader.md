# S6.3: Seed Data Definition & Loader Script

**Epic:** 6 — Crowdsourced Pool & Seed Data
**Depends-on:** S0.7
**Priority:** HIGH

## Context
Create the seed data pipeline: define 50 staple grocery products and create an idempotent CLI script that loads both product definitions and collected prices into the Comparison Pool DB. The script inserts products, chains, outlets, and prices with `source = 'manual_seed'`. It must be safe to run multiple times without creating duplicates (UPSERT by canonical name and chain). This single story replaces the former S6.1 (data definition) and S6.3 (loader) split — the JSON file definition is a prerequisite of the loader, not a standalone engineering task.

## Scope
### Product Definition (prerequisite)
- Define 50 canonical products across all 10 categories (Dairy, Bakery, Staples, Meat, Beverages, Produce, Snacks, Frozen, Baby, Household)
- Each product: canonical_name, category_id, typical_unit (e.g., "Full Cream Milk 1L", "White Bread 600g", "Basmati Rice 5kg")
- Categories weighted by grocery frequency: more Staples, Dairy, Produce items than Baby, Frozen
- Singapore-market-aware: includes Indian provision shop items (ATTA flour, lentils, cooking oil brands)
- Output as `scripts/seed/seed-data.json`: array of { canonical_name, category_name, unit, aliases[] }
- Aliases for common variations (e.g., "Full Cream Milk 1L" → aliases: ["FRESH MILK 1L", "MILK FULL CREAM 1L"])

### Loader Script
- CLI command or .NET console app / EF migration seed in `scripts/seed/`: reads `scripts/seed/seed-data.json` and `scripts/seed/seed-prices.json`
- Inserts products into Comparison Pool `products` table (UPSERT by canonical_name)
- Inserts retail chains (already seeded in S0.7 — skip if exists)
- Inserts outlets (UPSERT by chain + name)
- Inserts prices with `source = 'manual_seed'` (UPSERT by product + chain + month + price)
- Idempotent: running multiple times does not create duplicates or increment receipt_count incorrectly
- Logs: products created, prices inserted, duplicates skipped
- **Out of scope:** Seed data update/refresh, diff-based updates

## Acceptance Criteria
1. 50 products defined across all 10 categories in seed-data.json
2. Each product has canonical name, category, unit, and at least 2 aliases
3. Categories represented proportionally (not equal distribution)
4. Singapore-specific products included (ATTA, pandan, sambal, etc.)
5. Running the loader script populates products, chains, outlets, and prices
6. Running it again does not create duplicate entries
7. Products: canonical_name is unique; script UPSERTs
8. Prices: no duplicate rows for same product + chain + month + price combination
9. All seed prices have `source = 'manual_seed'`
10. Script logs summary: N products created, M prices inserted, K duplicates skipped
11. Contribution integrity: prices table contains NO user_id, bill_id, or full date columns
12. observed_month is YYYY-MM format only
13. Outlet data stored but not linkable to any user
