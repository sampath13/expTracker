# S7.2: Monthly Quota Enforcement (Scans + Comparisons)

**Epic:** 7 — Freemium Gating
**Depends-on:** S0.7, S4.3, S5.2
**Priority:** MEDIUM

## Context
Enforce the monthly scan and comparison quotas for free-tier users. Free users get 10 confirmed bill scans and 20 comparison queries per calendar month. Counters reset on the 1st of each month (SGT timezone). Premium and founder users have unlimited everything. This story combines the former S7.1 (tier model, now a prerequisite), S7.2 (scan quota), and S7.3 (comparison limit) into a single coherent quota enforcement unit.

## Scope
### Tier Model (prerequisite extension to User entity)
- Add Tier field to User entity: enum (free, premium, founder)
- Add ScansThisMonth counter + LastScanResetAt timestamp
- Add ComparisonsThisMonth counter + LastComparisonResetAt timestamp
- Default: Tier = 'free' for all new users (registration in S1.2)
- Migration for new columns
- Founder tier assignable manually (DB or admin endpoint)

### Scan Quota Enforcement
- Quota check in POST /bills/scan: if tier = free and scans_this_month >= 10 → return 402 with "Monthly scan limit reached"
- Counter reset: on first scan of a new calendar month, reset scans_this_month to 0 and update last_reset_at
- Counter increment: in POST /bills/confirm (S4.3) after successful save
- Premium/founder users: skip quota check entirely

### Comparison Quota Enforcement
- Quota check in GET /compare/item and POST /compare/basket: if tier = free and comparisons_this_month >= 20 → return 402 with "Monthly comparison limit reached"
- Counter increment on each comparison query response
- Counter reset alongside scan counter — shared month boundary logic in SGT timezone
- Premium/founder users: skip check entirely

- **Out of scope:** Mid-month tier upgrades (manual reset), rollover unused quotas, differentiated limits

## Acceptance Criteria
1. All new users default to 'free' tier with zeroed counters
2. Free user can confirm up to 10 bills and make 20 comparison queries per calendar month
3. 11th scan attempt returns 402 with clear error message
4. 21st comparison attempt returns 402 with clear error message
5. Both counters reset on the 1st of each month (SGT timezone)
6. Premium and founder users not limited — no 402 ever
7. Scan quota counter reflects confirmed bills only (not uploads or OCR calls)
8. Comparison counter accurately reflects API calls to /compare/* endpoints
9. Tier field retrievable via API for display (S7.4)

## Definition of Done
