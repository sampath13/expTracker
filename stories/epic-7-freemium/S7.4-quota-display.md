# S7.4: Mobile — Quota Display & Premium Upsell

**Epic:** 7 — Freemium Gating
**Depends-on:** S0.1, S0.2, S7.2
**Priority:** MEDIUM

## Context
Display the user's remaining scan and comparison quotas on appropriate screens. Free users see their remaining scans on the Home screen and comparison count on the Compare tab. When quota is exhausted, users see an inline premium upsell with a feature comparison table explaining the value of upgrading. Premium users see no quota (or an "Unlimited" badge). This story combines the former S7.4 (quota display) and S7.5 (upsell screen) since the upsell is a natural extension of the quota-exhausted state, not a standalone screen.

## Scope
### Quota Display
- Home screen: remaining scans display (e.g., "3/10 scans remaining this month") with progress bar
- Compare tab: remaining comparisons display (e.g., "15/20 comparisons remaining")
- Quota data fetched from user profile or a dedicated GET /user/quota endpoint
- Premium/founder users: no quota shown (or "Unlimited" badge)
- Quota updates after confirm (S4.3) and after comparison query (S5.2/S5.3)

### Quota-Exhausted State (includes premium upsell)
- At 0 scans remaining: scan FAB disabled; inline banner shown — "You've used all 10 scans this month"
- At 0 comparisons remaining: inline banner on Compare tab — "Comparison limit reached"
- Feature comparison table displayed inline within the exhausted state: Free vs Premium vs Founder
- Premium features listed: unlimited scans, unlimited comparisons, full expense history, spending trends, data export
- "Upgrade to Premium" CTA button (placeholder — no payment integration for MVP)
- Current user tier visually highlighted
- Founder tier shown for transparency with "Current plan" badge
- Free user sees upgrade CTA; Premium/Founder user sees "Current plan" badge, no upgrade button
- Same upsell accessible from Settings screen for proactive discovery

- **Out of scope:** Push notifications for quota exhaustion, mid-cycle usage graphs, payment flow

## Acceptance Criteria
1. Free user sees "X/10 scans remaining" on Home screen with progress bar
2. Free user sees comparison count on Compare tab
3. At 0 scans: scan FAB disabled, quota-exhausted banner displayed
4. At 0 comparisons: limit-reached banner on Compare tab
5. Exhausted state shows tier comparison table (Free vs Premium vs Founder)
6. Current user tier visually highlighted in comparison table
7. Free user sees upgrade CTA (placeholder); Premium/Founder see "Current plan" badge
8. Upsell accessible from Settings screen
9. Premium/founder users see no quota indicators (or "Unlimited")
10. All counts update in real time after relevant actions

## Definition of Done
- [ ] Quota display on Home screen (scan count + progress bar)
- [ ] Quota display on Compare tab (comparison count)
- [ ] Quota-exhausted state with tier comparison table
- [ ] Upgrade CTA placeholder in exhausted state
- [ ] Current tier highlighting logic
- [ ] Premium/founder: no quota UI
- [ ] Upsell accessible from Settings
- [ ] Real-time count updates after actions
- [ ] Ready for future payment integration
