# S5.3: Backend — Basket Comparison Endpoint

**Epic:** 5 — Comparison Engine
**Depends-on:** S5.2
**Priority:** MEDIUM

## Context
Create the batch comparison endpoint. Instead of calling `/compare/item` once per item (N calls for a receipt with N items), the mobile app sends all items at once and gets a consolidated response with per-item comparisons and an aggregate savings summary. This reduces chatty API calls and provides basket-level insight.

## Scope
- `POST /compare/basket` — accepts array of { product_id, user_price, user_chain, user_unit }
- Runs CompareItemAsync for each item
- Returns per-item comparisons + aggregate: total user spent, total best price, total savings, best overall chain recommendation
- Best chain recommendation: chain with the lowest total for the basket
- Summary text: "Shopping at [Best Chain] would save you $X on this basket"
- **Out of scope:** Shopping list optimization, multi-store basket splitting

## Acceptance Criteria
1. POST /compare/basket returns per-item comparison results
2. Aggregate summary includes total spent, total best price, total savings
3. Best overall chain recommendation provided
4. Unauthenticated → 401
5. Empty basket → appropriate validation error

## Definition of Done
- [ ] POST /compare/basket endpoint
- [ ] Per-item + aggregate comparison results
- [ ] Best chain recommendation
- [ ] Ready for mobile basket comparison view (future enhancement)
