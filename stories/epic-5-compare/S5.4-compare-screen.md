# S5.4: Mobile — Compare Screen (Explore Tab)

**Epic:** 5 — Comparison Engine
**Depends-on:** S0.1, S0.2, S5.2
**Priority:** MEDIUM

## Context
Build the dedicated Compare tab where users can search for any product in the catalogue and see its price across all chains, sorted cheapest first. This is the proactive exploration view — users don't need a receipt to use it. It complements the bill-detail comparison which is reactive (based on what they bought).

## Scope
- Compare screen with search bar at top
- Autocomplete search from product catalogue as user types
- After selecting a product: list of chains with prices, sorted cheapest first
- Each chain row shows: chain name, price per unit, savings/extra cost vs cheapest, last observed date
- Cheapest chain highlighted (green text or badge)
- Empty search state: "Search for a product to compare prices"
- No-data state: "Not enough receipts yet. Contribute yours to help!"
- Premium gate (S7.3): free tier limited to N comparisons/month; remaining displayed
- **Out of scope:** Barcode scanning, shopping list creation from comparison

## Acceptance Criteria
1. Search bar with autocomplete from product catalogue
2. Selecting a product shows chain prices sorted cheapest first
3. Cheapest chain visually highlighted
4. Each row shows price, savings, last observed date
5. No-data state explains why + invites contribution
6. Comparison count tracked and displayed (premium gate)
7. Search without results shows "No products found"

## Definition of Done
- [ ] CompareScreen with search + results list
- [ ] Autocomplete integration with GET /products/search
- [ ] Price comparison display per chain
- [ ] Cheapest chain highlighted
- [ ] No-data and empty states
- [ ] Comparison quota display (S7.3)
- [ ] Ready for integration with S5.5 (bill detail)
